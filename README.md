# KodRadar

@cagrikod için kişiselleştirilmiş içerik büyüme ve mentörlük dönüşüm paneli.

## Özellikler

- Herkese açık Instagram profilinden takipçi ve gönderi performansı yenileme
- Geçmiş viral formatlara göre içerik fikri analizi
- Viral sinyal kontrolü; uydurma izlenme tahmini yok
- 10K hedef senaryosu ve paylaşım arası etkisi
- Profil, bio, öne çıkanlar ve sabit gönderi rehberi
- 30 günlük içerik ve gelir planı

## Yerel çalışma

```bash
python server.py
```

Ardından `http://127.0.0.1:4173` adresini açın.

## Test

```bash
npm test
```

Canlı veri, yalnızca herkese açık kaynaklara dayanır. Instagram'ın gizli algoritmasına erişmez ve viral olma garantisi vermez.
